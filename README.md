# Toninho09 Tap

## How do I install these formulae?

`brew install toninho09/tap/<formula>`

Or `brew tap toninho09/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "toninho09/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
